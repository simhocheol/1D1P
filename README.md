# 1D1P

하루에 1퍼센트 먹기. 시장 이벤트와 기업 노출을 연결하는 한국어 시장 관찰 웹 서비스의 초기 MVP입니다. 일일 수익을 보장하는 서비스가 아닙니다.

## 실행

```sh
npm ci
npm run dev
npm run build
npm test
```

React 19, HeroUI v3, Tailwind CSS v4, Vite 기반입니다.

## 화면

- `/`: 월간 캘린더, 장전·장후 Driver 변화와 공식 발표 일정
- `/report`: 2026-10-02 사후 재구성 리포트, 원문·기업 노출·실제 반응
- `/universe`: 종목 검색, 관심 종목 저장, 개별 근거 추적
- `/settings`: 브라우저에 저장하는 발행 선호 설정

## 분석 체계

거시 6(수요·성장, 물가·비용, 금리·할인율, 신용·자금조달, 유동성·자금흐름, 환율), 산업·정책 3(정책·규제·시장 접근, 공급·경쟁 구조, 투자·기술 전환), 기업 3(매출·주문, 마진·현금흐름, 자본·기업 사건).

이벤트 → Driver → 기업 노출 → 전달 가설 → 실제 반응을 기록합니다. 변화 강도·노출 정도·근거 신뢰도·반응 일치도는 구분합니다. 시장 지수·VIX·기술 지표는 원인 Driver와 분리합니다.

## 현재 데이터와 한계

공식 BLS·연준·Tesla IR 일정과 기존 출처 기반 10월 2일 리포트를 고정 데이터로 사용합니다. 주식 5개만 반영했으며 S&P 500 전체·ETF 수집, 인증, 서버 DB, OpenAI 호출, 예약 발행, 웹·모바일 푸시는 아직 연결되지 않았습니다. 가격 기사와 공식 통계 출처는 화면에서 추적할 수 있습니다. 근사 수익률·정성 노출·미확인 항목을 구분합니다.

향후 서버 데이터 계층에서 가격·OHLCV 제공처, 공식 캘린더, 기업 공시를 수집하고 원문 URL·게시 시각·조회 시각·수정 이력을 저장해야 합니다. 모델은 근거 요약에 사용하며 가격과 기술 지표를 생성하지 않습니다. API 키는 서버에만 보관하며 `VITE_` 환경 변수에 넣지 않습니다.

## 배포

Vercel에 GitHub 저장소를 연결하면 `npm run build`, `dist` 출력과 `vercel.json` 라우팅을 사용할 수 있습니다. 현재 버전은 정적 프런트엔드입니다. 예약 발행·알림·데이터 수집 백엔드는 별도 구현이 필요합니다.
