# 1D1P

하루에 1퍼센트 먹기. 시장 이벤트와 기업 노출을 연결하는 한국어 시장 관찰 서비스입니다. 일일 수익을 보장하지 않습니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run test:collector
npm run build
```

브라우저 검증: 로컬 서버 실행 후 `npm run test:browser`.
React 19, HeroUI v3, Tailwind CSS v4, Vite 기반입니다.

## 운영 화면

- `/`: 공식 일정, 자동 수집 발표, 검증 기록만 표시하는 월간 Driver 관측.
- `/report`: 최신 검증 리포트. `?date=2026-10-01` 등으로 날짜 선택.
- `/universe`: 출처가 검증된 TSLA/NKE 반응. 전체 종목·ETF·실시간 가격은 미연결.
- `/settings`: 실제 수집 성공·실패와 미연결 서비스 상태.

샘플 리포트는 운영 경로에서 제거했습니다. 월간 점은 검증 기록의 존재만 나타내며 미검증 강도 점수를 사용하지 않습니다. 누락은 영향 부재가 아닙니다.

## 실제 데이터

- `src/verified-sessions.js`: 10월 1·2일 수동 검증, BLS/Tesla/Nike 원문과 별도 마감 보도.
- `src/calendar-data.js`: 공식 출처에서 수동 검토한 발표 예정 일정. 자동 일정 수집과 구분합니다.
- `public/data/official-feed.json`: 연준 발표·연설 및 BLS 고용/CPI/PPI RSS 수집 결과.
- `scripts/collect_official.py`: 공식 XML 파서, ET 날짜, 조회 시각, 최초 조회 시각, URL, 재시도, 실패 시 기존 기록 유지, 원자적 저장.

RSS는 제목·게시 시각·원문 링크만 수집합니다. 원문 분석·가격 인과관계·Driver 강도는 자동 생성하지 않습니다. BLS는 환경에 따라 HTTP 403을 반환하며 성공으로 위장하지 않습니다.

## 자동 수집과 배포

GitHub Actions `Collect official data`는 매시간 예약을 확인하고 미국 동부 평일 09시·17시 이후 하루 두 슬롯에서 수집합니다. IANA 시간대로 서머타임을 처리하고 같은 슬롯의 중복 실행은 막습니다. GitHub 예약 실행은 지연될 수 있습니다. 휴장일에도 평일에는 공식 자료를 수집합니다.

수집 기록 변경을 GitHub main에 커밋하면 기존 Vercel Git 연동이 운영 배포합니다. 실패한 수집기의 상태 파일도 기존 데이터와 함께 반영하고 워크플로는 실패로 표시합니다. GitHub의 workflow contents-write 권한과 Vercel Git 연동이 필요합니다.

수동 수집: `npm run collect` 또는 GitHub Actions의 Run workflow.
운영 상태: GitHub Actions와 Vercel deployments에서 확인합니다.

## 아직 필요한 연결

가격/OHLCV 제공처, S&P 500·ETF 전수 수집, 원문 자동 분석, OpenAI 요약, 예약 리포트 생성, 웹·모바일 푸시는 미연결입니다. 현재 자동화는 공식 발표 목록의 수집과 배포이지 완성된 하루 두 번 분석 리포트 발행이 아닙니다.

API 키는 GitHub Secrets 또는 서버 환경 변수에만 등록합니다. `.env`는 Git에서 제외하며 `VITE_` 환경 변수로 비밀 키를 노출하지 않습니다. 데이터 제공처 계약·재배포 권한 확인 후 가격 연결을 추가해야 합니다.

## OpenAI 키 설정

`/settings`의 입력란은 마스킹된 키 연결 테스트용입니다. Vercel Function `/api/openai-connection`을 통해 모델 목록 조회 권한을 확인합니다. 연결 검증 API는 키를 응답·로그에 남기지 않습니다. 관리자 인증 후 검증이 성공하면 설정 화면에서 암호화 저장을 자동으로 이어서 실행하며, 입력란은 성공·실패 후 지웁니다. 실제 생성 API 권한과 결제 상태를 검증하는 테스트는 아닙니다.

예약 발행용 영구 키는 설정 화면에서 관리자 인증 후 암호화 저장하거나 GitHub Secrets에 직접 `OPENAI_API_KEY` 이름으로 등록합니다. 저장만으로 분석 리포트 생성이 활성화되지는 않습니다.

무료 가격 API 비교와 라이선스 제약은 `MARKET_DATA_PROVIDERS.md`와 설정 화면에 있습니다. Alpaca는 개인 개발용 우선 후보이며 공개 재배포는 별도 확인이 필요합니다.

## Alpaca 연결

시장 데이터 제공처를 Alpaca Basic / IEX로 설정했습니다. `/settings`에 API Key와 Secret Key를 입력해 읽기 전용 일봉 접근을 확인할 수 있습니다. 테스트는 AAPL IEX 일봉만 조회하며 가격 응답은 저장하거나 공개하지 않습니다. 관리자 인증 후 연결 확인에 성공한 키는 자동으로 암호화 저장합니다. 주문·계좌 API는 호출하지 않습니다.

사이트의 암호화 저장은 두 키를 하나의 `ALPACA_CREDENTIALS_JSON` Secret에 묶어 원자적으로 등록합니다. 다음 수집 슬롯 또는 수동 실행에서 서버 인증·일봉 접근을 검증합니다. 기존 `ALPACA_API_KEY`, `ALPACA_SECRET_KEY` 수동 등록도 번들이 없을 때 지원합니다. `public/data/market-connection.json`에는 연결 상태와 조회 여부만 저장합니다. 키·가격·계좌 정보는 포함하지 않습니다.

현재 공개 가격 수집·표시는 비활성화되어 있습니다. 개인 개발용 무료 데이터 접근은 서비스 재배포 권한이 아니므로 이용 허가 확인 후 가격 수집·기술지표 파이프라인을 연결해야 합니다. IEX 거래량은 전체 시장 거래량이 아닙니다.

## 사이트에서 암호화 저장

### 종목·ETF 실제 수집

### Driver → 섹터 → 변화 종목 리포트

`/report`에서 관리자 인증·복호화 후 전체 목록 대신 룰 기반 변화 감지 종목만 표시합니다. 기준은 절대 등락 1% 이상이면서 (이전 최대 60개 수익률 대비 2 표준편차 / 이전 20일 평균 거래량의 2배 / 섹터 ETF 대비 1.5%p 차이) 중 하나입니다. 변동성은 현재 거래일을 제외해 추정하며 같은 ET 거래일만 비교합니다. 누락은 0으로 대체하지 않습니다. 기준은 초기 휴리스틱으로 예측 성능이나 유의확률을 검증한 모델이 아닙니다.

섹터 ETF·시장 대비 상대 강도·상승 종목 비중을 집계합니다. 구성 종목 60% 이상 수집된 섹터만 반응을 판정합니다. 5개 ETF 대리지표가 1% 또는 1.5σ 이상 움직이고, 과거 수익률 상관 절댓값 0.35 이상이며 예측 방향과 섹터 방향이 일치하면 영향 **후보**로 연결합니다. 가격 상관을 거시경제의 인과 효과로 확정하지 않습니다. 기관 발표와 종목 뉴스는 직전 거래일 장 마감부터 해당 날짜 장 마감 전까지를 근거 구간으로 사용합니다. 주말 발표와 직전 장후 발표도 다음 거래일 구간에 포함합니다. 과거 날짜 조회는 현재 구성 종목과 최근 일봉 보관 범위에 한정되며 뉴스는 최근 7일의 제한된 표본입니다.

`collect_market.mjs`는 현재 S&P 500 구성 증권과 선정한 ETF 29종을 갱신하고, Alpaca IEX 분할 조정 일봉을 최근 180일 구간에서 페이지네이션 수집합니다. 구성 목록은 datasets 프로젝트의 커뮤니티 관리 CSV이며 S&P 공식 라이선스 피드가 아닙니다. 과거 날짜의 구성 종목을 복원하는 백테스트용 목록도 아닙니다.

가격·거래량·뉴스는 공개 Git에 커밋하지 않습니다. 공개 저장소의 Artifact도 다운로드될 수 있으므로 Alpaca Secret Key에서 HKDF로 유도한 키와 임의 salt/nonce를 사용해 AES-256-GCM으로 파일 자체를 암호화합니다. GitHub Actions `market-data` Artifact에 암호문을 7일간 보관하며 `/universe`에서 simhocheol 토큰과 수집 당시 Alpaca Secret Key로 조회합니다. 조회 토큰에는 Repository permissions의 **Actions: Read** 권한이 추가로 필요합니다. 리포트 조회용 토큰·Secret 및 마지막 성공 결과는 이 브라우저의 IndexedDB에 AES-GCM 암호문으로 보관합니다. 암호화 키는 추출 불가 Web Crypto CryptoKey로 동일한 프로필에 보관합니다. 설정에서 새로 인증·Alpaca 저장한 경우 자동으로 재사용합니다. 이전 버전은 GitHub에만 저장했으므로 원문을 복구할 수 없고, 그 경우 최초 1회 기기 연결이 필요합니다. 키를 교체하면 다시 수집해야 합니다. 원문은 다음 예약 수집 때 갱신되며 장중 미완성 일봉은 제외합니다.

종가·전일비·IEX 거래량·20/50일 SMA·14일 Wilder RSI·이전 20일 평균 대비 거래량을 계산합니다. ETF 대리지표와 최근 최대 60개 일간 수익률의 상관·베타는 통계적 동반 움직임이며 거시 Driver 인과 기여도가 아닙니다. 같은 ET 거래일 기관 발표와 최근 7일 관련 뉴스 링크를 상세 화면에 표시하지만 가격 변화의 원인으로 확정하지 않습니다. 뉴스는 50종목 배치당 최근 최대 50건으로 전수 수집을 보장하지 않습니다. 미확인 값은 비워 두며 OpenAI 인과 분석, 전 세계 ETF 전수 목록, 웹·모바일 푸시는 별도 미구현입니다.

1. simhocheol 계정의 Fine-grained GitHub token을 생성합니다. 1D1P 저장소만 선택하고 Repository permissions의 Secrets를 Read and write로 설정합니다.
2. 설정 화면의 관리자 인증에 입력합니다. 조회용 토큰은 기기 암호화 저장소에 보관해 화면 이동·새로고침 후에도 재사용하며 Git·서버 파일에는 저장하지 않습니다.
3. 제공처 키를 입력하고 연결 테스트를 누릅니다. 연결 확인에 성공하면 자동으로 암호화 저장합니다. 연결 성공과 저장 실패는 구분해 표시합니다. 별도 암호화 저장 버튼도 유지합니다.

서버는 GitHub에서 소유자를 확인한 다음 저장소 공개키로 libsodium sealed-box 암호화를 수행합니다. GitHub에 전송하는 Secret 값은 암호문입니다. 관리자 인증 없이 저장·조회할 수 없으며 simhocheol 이외의 계정은 거부합니다. 새로고침·재배포 후에도 GitHub가 Secret을 보관합니다. 상태 조회는 존재 여부·변경 시각만 반환하고 원문이나 암호문을 브라우저에 돌려주지 않습니다.

GitHub Actions는 저장된 Alpaca 번들을 환경 변수로 받아 기존 읽기 전용 검증에 사용합니다. 사이트 런타임은 GitHub Secrets의 원문을 읽을 수 없습니다. 삭제는 GitHub 저장소 Secrets 화면에서 가능하며 교체는 동일한 암호화 저장 버튼으로 수행합니다. API 키와 관리자 토큰은 채팅에 보내지 않습니다.

## 조회 연결과 결과 보관

리포트는 최초 기기 연결 이후 조회 버튼만으로 갱신합니다. 화면 진입·새로고침·거래일 선택만으로는 서버 조회를 실행하지 않습니다. 마지막 성공 결과와 펼친 종목 수를 복원하고, 재조회 중이거나 실패하면 기존 결과를 유지합니다. 새 결과와 기기 보관이 모두 성공한 후 화면을 교체합니다. settings의 인증 해제 또는 리포트의 기기 연결 삭제는 로컬 인증·결과를 삭제하며 GitHub Secrets는 삭제하지 않습니다.

보관은 같은 사이트·브라우저 프로필에 한정되며 다른 기기에 동기화되지 않습니다. 로컬 암호화는 원문 저장을 방지하지만 동일 출처의 악성 스크립트, 브라우저 프로필 탈취, 확장 프로그램, 잠금 해제된 공유 기기로부터 보호하는 인증 경계는 아닙니다. 공용 기기에서는 보관 정보를 삭제하고 계정 토큰 만료·최소 권한을 설정하세요. 암호화 저장소가 사용 불가하거나 저장 한도가 초과되면 결과를 교체하지 않고 오류를 표시합니다.

UI는 기존 @heroui/react v3와 @heroui/styles를 사용합니다. https://github.com/heroui-inc/heroui 의 compound Card, Chip, TextField/Label/Input 및 Button을 활용하고 무채색 surface/field 토큰을 적용했습니다. 의미 있는 가격 방향·캘린더 반응 표시의 색상은 유지합니다.
